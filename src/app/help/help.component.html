A useful mental model

Find is built to reduce the distance between curiosity and clarity.

Ask naturally

Use the words you would actually use. Find is built for questions, not query syntax.

Read before clicking

The first result is meant to give you useful orientation before you open the source.

Refine, don’t restart

Use context pills, alternatives, and All results when the first result is close but not quite enough.
